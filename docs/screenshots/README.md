# Screenshots checklist

Capture these and save them with the exact filenames below. The
project README and the Application section of the FYP doc reference
them by these paths.

## Mobile (1080×2400 portrait, from the EAS-built APK on Android)

| Filename | What to capture |
|---|---|
| `mobile-scan.png` | The Scan tab with the camera-or-gallery buttons |
| `mobile-result.png` | A ResultCard after scanning a clear dish (e.g. biryani) — including macros + AI insight |
| `mobile-result-low-conf.png` | A ResultCard showing the top-3 picker (low-confidence case) |
| `mobile-history.png` | History tab with date-grouped scans |
| `mobile-insights.png` | Insights tab after ≥3 scans (chart visible) |
| `mobile-chatbot.png` | Chatbot tab after one Q&A exchange |
| `mobile-profile.png` | Profile tab with goal + restrictions shown |

## Web (1440×900 landscape, Chrome at 100% zoom)

| Filename | What to capture |
|---|---|
| `web-landing.png` | The Landing page hero |
| `web-dashboard.png` | The Today/Scan page with upload zone + a scan result below |
| `web-history.png` | History page with circular thumbs + macros expanded for one row |
| `web-insights.png` | Insights page with the 4 stat cards + 2 charts |
| `web-chatbot.png` | Chatbot with a recent exchange |
| `web-profile.png` | Profile with editable goal + restrictions + About-the-Model accordion expanded |

## How to capture

- **Android**: power + volume-down. Pull the resulting PNG off your
  phone via USB, Google Drive, or just upload to a chat tool.
- **Web**: F12 (DevTools) → toggle device toolbar OR use the OS
  screenshot tool (Win+Shift+S on Windows).

Once the PNGs are saved here, the README + AppDocs/01_application.md
will pick them up automatically — no further code changes needed.
